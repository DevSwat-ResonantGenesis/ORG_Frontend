# 🚀 How to Create Your First AI Project

Welcome! This guide will walk you through creating your first AI-generated project in the Resonant IDE.

## 📋 Quick Start (3 Steps)

### **Method 1: From the IDE (Recommended)**

1. **Open the IDE Menu**
   - Click the **☰ (hamburger menu)** button in the top-left of the IDE
   - Or press `Cmd/Ctrl + Shift + P` to open Command Palette

2. **Click "✨ Generate Project with AI"**
   - This will take you to Resonant Chat with project generation mode enabled
   - You'll see a project builder interface

3. **Describe Your Project**
   - Type what you want to build, for example:
     - `"Build a React todo app"`
     - `"Create a Python Flask API"`
     - `"Make a Node.js chat server"`
   - Click the **"Build Project"** button or press Enter

4. **Wait for Generation** (10-15 seconds)
   - The AI will generate all project files
   - Files will appear in the project builder

5. **Review & Download**
   - Browse generated files in the left panel
   - Click any file to preview its code
   - Click **"Download All as ZIP"** to save the project

6. **Upload to IDE**
   - Go back to the IDE
   - Click **☰ Menu → Upload Project**
   - Select the downloaded ZIP file
   - Your project is now ready to edit!

---

### **Method 2: From Resonant Chat**

1. **Navigate to Resonant Chat**
   - Click **"Resonant Chat"** in the navigation menu
   - Or go to `/resonant-chat`

2. **Click "Build Project" Button**
   - Look for the **"Build Project"** button in the chat interface
   - This enables project generation mode

3. **Describe Your Project**
   - Type your project description
   - Examples:
     - `"Create a React dashboard with charts"`
     - `"Build a REST API with Express and MongoDB"`
     - `"Make a Python data analysis tool"`

4. **Follow Steps 4-6 from Method 1**

## 🎯 Tips for Best Results

1. **Be Specific**
   - ✅ Good: `"Create a React todo app with drag-and-drop"`
   - ❌ Vague: `"Make an app"`

2. **Mention Technologies**
   - Specify frameworks: React, Vue, Angular, Express, Flask, etc.
   - Mention databases: MongoDB, PostgreSQL, MySQL
   - Include styling: Tailwind CSS, Material-UI, Bootstrap

3. **Describe Features**
   - List key features you want
   - Mention UI requirements
   - Specify authentication needs

4. **Project Type Hints**
   - `"web app"` → React/Vue frontend
   - `"API"` → Backend with Express/Flask
   - `"CLI tool"` → Command-line application
   - `"library"` → Reusable code package

## 🔧 After Generation

### Upload to IDE
1. Download the generated ZIP file
2. In IDE: **☰ Menu → Upload Project**
3. Select the ZIP file
4. Your project files will appear in the file tree

### Edit Your Project
- Click any file in the file tree to open it
- Edit code in the Monaco Editor
- Save with `Cmd/Ctrl + S`
- Run your project with the **Run** button

### Use AI Features
- **Chat Panel**: Ask questions about your code
- **Code Search**: Find code patterns across files
- **Refactoring**: Improve code structure
- **Debugger**: Step through code execution

## 🆘 Troubleshooting

### Project Generation Failed
- **Check your description**: Make it more specific
- **Try again**: Click "Try Again" in the error message
- **Simplify**: Break complex projects into smaller parts

### Files Not Appearing
- **Check browser console**: Look for errors
- **Refresh page**: Sometimes helps with loading
- **Check network**: Ensure backend is running

### Upload Not Working
- **File format**: Must be a ZIP file
- **File size**: Check if file is too large
- **Backend connection**: Ensure API is accessible
