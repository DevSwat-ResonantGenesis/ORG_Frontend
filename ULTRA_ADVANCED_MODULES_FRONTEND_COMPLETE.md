## 🎯 How to Use

### Accessing Modules:
1. Click **☰ Burger Menu** (top-left)
2. Toolbar buttons appear
3. Click module button to open panel
4. Panel opens on right side

### Module 1: AI Dev Agent
1. Open panel
2. Enter task description
3. Click "Build Context"
4. Click "Generate Patch"
5. Review preview
6. Click "Apply Patch"

### Module 2: Code Graph
1. Open panel
2. View graph statistics
3. Switch tabs (Graph/Dependencies/Usage)
4. Search for symbol usage

### Module 4: API Inspector
1. Open panel
2. Select HTTP method
3. Enter URL
4. Add body (if POST/PUT)
5. Click "Send"
6. View response

### Module 5: Usage Tracking
1. Open panel
2. Select period (today/week/month)
3. View cost and metrics
